# Изменения

## 0.1.0

- Первая версия TUI-плагина OpenCode V2 (`opencode.go-cost`).
- Оценка стоимости сессии для провайдера OpenCode Go (`opencode-go`)
  добавляется в `prompt.footer.status` как `≈$0.12`.
- Метка показывается только при отсутствии встроенной стоимости
  (`session.cost <= 0`), только для OpenCode Go, при наличии токенов и цен в
  каталоге моделей.
- Расчёт: `input`, `output + reasoning`, чтение и запись кэша; цены каталога
  за 1M токенов.
- Поддержка контекстных tier-цен: `total = input + cache.read + cache.write`,
  строгое `total > tier.size`, побеждает наибольший подходящий tier, иначе
  базовая цена.
- Клик по метке открывает диалог с моделью, токенами, выбранным тарифом,
  ценами и итоговой оценкой.
- Чистая логика `plugin/cost.js` без импортов OpenCode и юнит-тесты
  `tmp/test-cost.mjs`.
- Серверная заглушка `plugin/index.js`, установка через `install.bat`
  (учитывает `XDG_CONFIG_HOME`).
- Без сети и внешних зависимостей.
