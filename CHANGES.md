# Изменения

## 0.2.0

- Стоимость теперь показывается **на месте встроенной**: рядом со счётчиком
  токенов, как `470.3K (48%) · $0.17`, без префикса `≈` и без отдельной метки
  в конце статуса. Формат совпадает со встроенным (`Intl.NumberFormat`,
  `style: "currency"`, `USD`).
- Реализовано подменой общего метода `context.data.session.cost`: это тот же
  объект данных, который используют встроенный футер (`opencode.prompt.footer`)
  и встроенный компонент Context в боковой панели, поэтому «spent» в сайдбаре
  тоже показывает оценку.
- Подмена работает только когда встроенная стоимость не положительна: при
  `session.cost > 0` возвращается нативное значение. Для корневой сессии
  оценка суммируется по семейству субагентов (как и нативный метод), для
  субагента — только по нему самому.
- Если объект данных заморожен и метод не перезаписывается, плагин
  откатывается на прежнее поведение: метка `≈$0.12` в
  `prompt.footer.status` и диалог с расшифровкой по клику.
- При выгрузке плагина исходный метод восстанавливается (cleanup).
- Новый модуль `plugin/patch.js` без импортов OpenCode и юнит-тесты
  `tmp/test-patch.mjs`.

## 0.1.0

- Первая версия TUI-плагина OpenCode V2 (`opencode.go-cost`).
- Оценка стоимости сессии для провайдера OpenCode Go (`opencode-go`)
  добавляется в `prompt.footer.status` как `≈$0.12`.
- Метка показывается только при отсутствии встроенной стоимости
  (`session.cost <= 0`), только для OpenCode Go, при наличии токенов и цен в
  каталоге моделей.
- Расчёт: `input`, `output + reasoning`, чтение и запись кэша; цены каталога
  за 1M токенов.
- Поддержка контекстных tier-цен: `total = input + cache.read + cache.write`,
  строгое `total > tier.size`, побеждает наибольший подходящий tier, иначе
  базовая цена.
- Клик по метке открывает диалог с моделью, токенами, выбранным тарифом,
  ценами и итоговой оценкой.
- Чистая логика `plugin/cost.js` без импортов OpenCode и юнит-тесты
  `tmp/test-cost.mjs`.
- Серверная заглушка `plugin/index.js`, установка через `install.bat`
  (учитывает `XDG_CONFIG_HOME`).
- Без сети и внешних зависимостей.
